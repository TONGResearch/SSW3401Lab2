# SSW3401 Lab 2 — Understanding the Basics of Flutter GUI

Flutter app for the course video's GUI section through the image example.

## Run

1. Open this folder in Android Studio and start an emulator or connect a phone.
2. Run `flutter pub get` and `flutter run`.
3. Tap the four navigation icons to switch screens.

## What is included

- `lib/main.dart` sets up the `MaterialApp`.
- `lib/screens/app_shell.dart` uses `setState` to switch between four tabs.
- `lib/screens/home_screen.dart` builds the header with `Row` and `Column`.
- `lib/styles/app_styles.dart` contains shared text styles.
- `assets/images/logo.png` is a custom plane icon displayed with `AssetImage`.
- Search, Tickets, and Profile are placeholder screens at this point in the video.

Reference video: [Flutter Course for Absolute Beginners](https://www.youtube.com/watch?v=DsTMhjaRQws).
